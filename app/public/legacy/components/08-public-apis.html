What this means

Enabled in Radar does not always mean freely callable from the browser.

Radar should call these sources from the backend only. Some are live immediately, some need API keys, and Reddit/Common Crawl style sources require governance or batch ingestion before production use.

  1. Use the backend catalogue as the source of truth for enabled sources.
  2. Add server-side keys on Render for key-required sources such as YouTube.
  3. Use domain refresh and AI discovery jobs to turn source evidence into Radar signals.
